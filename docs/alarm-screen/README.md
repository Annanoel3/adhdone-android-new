# The phone's alarm screen, drawn from the real code

- `alarm-screen-build49.jpg`: the alarm screen from Android build 49 on, in ten situations (dark and light theme, a text task with its third button, a small phone with a large font, an event, two tasks ringing together, the eased plan's alarm, a timer's end, the earlier screen that the off switch brings back, a small phone with every button showing). Drawn on Nov 16 2026 by running `AlarmActivity` with `activity_alarm_v2.xml` in a Robolectric test, not by hand.
- `store-slide-1-screen.jpg`, `store-slide-4-screen-plain.jpg`: the two screens used in the Play Store pictures 1 and 4.

How to draw them again after a change: see RULES.md, "The phone's alarm screen from build 49" (the row's last sentence). Look at the picture before describing the screen to anyone.
